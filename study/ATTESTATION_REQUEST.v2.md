# Contemporary Code Authorship Attestation Request

This request supports a public research study estimating agent-authored code in
a fixed repository cohort. We selected candidate repositories before inspecting
classifier outputs. Participation is voluntary. A “no,” an uncertain answer, or
no response is retained as such and never converted into a label.

Please respond only if you have direct authority and knowledge sufficient to
make one of the exact statements below. Repository-wide policies, guesses based
on style, and “no known AI use” are not sufficient.

## Human-written commit attestation

> I am **[GitHub identity]**, a **[maintainer/author role]** for
> **[owner/repository]**. I directly attest that the following exact commits
> were written without code, tests, comments, or documentation being generated
> or modified using an AI coding agent, LLM, or generative-AI code assistant:
>
> **[full 40-character commit IDs, one per line]**
>
> This statement covers the surviving Python/Go production code and tests
> introduced by those commits. I understand that formatting tools, compilers,
> code generators, and non-generative static analysis are not considered AI
> assistance for this statement. My attestation is based on **[personal
> authorship / direct maintainer review with stated basis]**.

The commits must be dated from 2024-01-01 through 2026-07-24 inclusive. We need
at least 2,000 surviving eligible lines from the repository, but respondents
should not select commits based on source style. It is acceptable to attest a
larger exact set or to decline.

## Agent-generated commit/history attestation

> I am **[GitHub identity]**, a **[maintainer/author role]** for
> **[owner/repository]**. I directly attest that **[the complete repository
> history / the following exact full commit IDs]** was generated by AI coding
> agents, with human activity limited to directing, reviewing, selecting, or
> applying the generated work:
>
> **[full 40-character commit IDs, or “complete history through COMMIT”]**
>
> This statement covers surviving Go production code and tests and is based on
> my direct knowledge of the development process.

## Publication and withdrawal

Please provide the attestation in a durable public GitHub comment or a signed
statement whose checksum can be published. The study records the statement,
repository, exact commits, attestor identity/authority, timestamp, and source
URL. Raw email addresses or unrelated personal information are not published.
An attestation may be withdrawn before the response ledger is frozen for model
fitting.

Questions may be answered without making an attestation. If the requested scope
is ambiguous or mixes human and agent-written commits, we will record it as
ineligible rather than infer a label.
